# Reliable supervision options without clinical review

Research date: 2026-09-25. Planning evidence for **Establish reliable supervision options without clinical review**. No private reports were inspected or transmitted, weights downloaded, extraction performed, or experiments launched. Recommendations below are proposed decisions, not performance results or model-use approval.

## Recommendation

Keep reference-only and frozen deterministic supervision as comparators. Evaluate **one local multilingual report extractor**, with conservative abstention and target-specific reliability accounting, before paying the queue cost of another image-training comparison. Reuse frozen learned outputs only if their provenance and eligibility pass review; existing aggregate accuracy does not admit them automatically. Defer image–report representation learning until an image baseline demonstrably learns and a bounded compute proposal exists.

Neither these sources nor the current data establish a route guaranteed to private first place. The 58 reference studies constrain what label reliability and improvement can be demonstrated, especially by target and language.

## What has already been measured

The local tracker is the primary record of these project results:

- [Evaluate fold-specific deterministic report extraction](../../.scratch/rsna-2026-fresh/issues/15-evaluate-fold-specific-deterministic-report-extraction.md): 4,407 reports, 58 reference studies and 4,349 report-only studies; 8,698 report-only fold-training occurrences. Mean target coverage on reference reports was 0.112069. Selective macro accuracy was 0.896054 across eleven defined targets; Medial OA had no confident calls, so twelve-target macro accuracy was undefined. High selective accuracy alone therefore does not demonstrate useful coverage.
- [Compare one approved local language-model extractor](../../.scratch/rsna-2026-fresh/issues/16-compare-one-approved-local-language-model-extractor.md): the intended path became Astra Medium through the subscription, superseding the old local FLAN implementation. Corrected evidence records 325/370 correct supervised calls (87.8%) versus 68/78 (87.2%) for the deterministic extractor; common-target macro accuracy was 0.8614 versus 0.8961. Agreement on all 75 shared calls does not validate the additional learned calls. No admission policy was predeclared. The existing learned artifact remains unadmitted, and this research does not authorize further remote processing.
- [Measure the controlled benefit of report supervision](../../.scratch/rsna-2026-fresh/issues/18-measure-the-controlled-benefit-of-report-supervision.md): corrected comparison preserved the reference exposure sequence and added deterministic report supervision. Across 58 OOF studies, macro-AUC delta was −0.000911, paired 95% study-bootstrap interval [−0.027593, 0.026657]. Only 351/358/352 valid weak-label entry exposures were added per fold, over 100 updates each. This is inconclusive evidence for that narrow configuration; it establishes neither benefit nor futility of report supervision generally.

## Semantic boundary

Use the existing [authority and interpretation register](../evidence/ticket-14-report-interpretation.md) as the starting specification. Its current definitions distinguish high-grade ACL/MCL tears from lesser findings; meniscal tears from intrasubstance degeneration; compartment-specific substantial OA/cartilage loss from mild findings; substantial effusion and Baker cyst from small findings; and acute fracture/impact contusion from unsupported alternatives. Synovitis requires its own explicit evidence. Do not broaden those definitions from an LLM's medical knowledge.

The register links the [host label definition](https://www.kaggle.com/competitions/rsna-knee-abnormality-detection/discussion/733343) and [host report clarification](https://www.kaggle.com/competitions/rsna-knee-abnormality-detection/discussion/733826). Both live pages returned no readable body in this research session. The semantic summary above is inherited local evidence, **not fresh independent verification** of their contents. Any changed interpretation needs recoverable host support; uncertain cases remain masked without a clinical reviewer.

Preserve positive, negative, not-mentioned, uncertain, unknown and extraction-failed separately. Only supported positive/negative calls enter masked supervision, and reference labels override report-derived disagreements. Missing mention cannot establish absence. Require the relevant structure, laterality where available, present versus historical status, severity and negation scope. Contradictory statements, ambiguous compartment, and unsupported fracture/edema variants should abstain. These are proposed operating rules consistent with the existing register, not new clinical labels.

[CheXpert](https://arxiv.org/abs/1901.07031) is primary evidence that radiology report labelers can represent uncertainty and that different uncertainty-handling choices can be evaluated. Its observations and evidence concern chest radiographs; importing its labels or uncertainty-to-negative policy into these knee targets would be an unsupported transfer.

## Bounded shortlist

| Route | Why evaluate it | Boundary and cost |
| --- | --- | --- |
| Frozen deterministic labels | Reproducible low-cost comparator already measured locally | English-only narrow vocabulary and low coverage; rerunning the same configuration is not a new hypothesis. CPU extraction already demonstrated within existing limits. |
| Frozen Astra artifact, if admissible | Existing extra coverage could avoid another extraction run | Audit exact prompt/output hashes, report cohorts, remote-processing eligibility and adaptation lineage. Use only a prospective admission policy evaluated without tuning against its held-out examples. No automatic admission based on historical averages. |
| One new local extractor: `Qwen/Qwen3-8B` | Explicit multilingual capability and locally runnable public weights offer a concrete alternative to narrow English rules | Freeze one prompt and decoding configuration; request structured states plus locally stored evidence spans. Benchmark a bounded eligible training-side sample first. Model claims do not establish knee-label accuracy. |
| Image–report representation pretraining, later | Uses report information without committing every sentence to a binary target | Requires new training and careful language/negation handling. Compare against matched image-only pretraining and reference fine-tuning; do not treat report retrieval as proof of twelve-target image performance. |

The [official Qwen3-8B card](https://huggingface.co/Qwen/Qwen3-8B) identifies an 8.2-billion-parameter model, Apache-2.0 license, support for more than 100 languages/dialects, local Transformers loading and a switch to disable thinking. This is the exact candidate identity, not a recommendation to chase newer releases. The card does not establish clinical extraction accuracy or competition eligibility. Pin the eventual weight revision, tokenizer and runtime before any use.

**Resource estimate, not a measurement:** 8.2 billion parameters at two bytes each imply about 16.4 GB of weight storage alone; a four-bit representation has a roughly 4.1 GB mathematical weight floor. Quantization metadata, runtime, activations and KV cache add memory, and conversion can need more RAM. Neither number is a VRAM guarantee. Start with batch size one, bounded input/output lengths and non-thinking mode; measure actual peak memory and throughput before requesting a full run. CPU quantized inference is a fallback hypothesis, not an established fit within six hours. Quantized outputs require their own reliability comparison. No GPU type, free allocation or queue duration was verified here.

[ConVIRT](https://arxiv.org/abs/2010.00747) provides primary evidence for learning image representations from paired reports and later using the image encoder for classification. Its reported medical-image experiments motivate an investigation, not a knee-MRI performance prediction. [MedCLIP](https://arxiv.org/abs/2210.10163) highlights the problem of treating semantically similar unpaired medical examples as contrastive negatives. These findings support deferring a naive all-pairs contrastive implementation until a concrete pairing/loss design is justified.

The [Stanford MRNet resource](https://stanfordmlgroup.github.io/projects/mrnet/) concerns general abnormality, ACL tear and meniscal tear. Its labels cannot be substituted for this competition's twelve definitions, including medial/lateral distinctions and severity thresholds. External data or checkpoint use also needs competition eligibility, access terms and overlap review. No external knee dataset is admitted by this report.

## Evaluation required before training admission

The following is a proposed protocol, not completed evaluation:

1. **Freeze cohort boundaries first.** Use the versioned patient/study grouping and fold manifest; investigate duplicate or related exams before extraction. For each consuming fold, exclude held-out studies and their reports from rule development, prompt examples, translation adaptation, extractor fine-tuning, confidence thresholds and all teacher/student/pretraining stages. Under the present project boundary, keep report-only studies in their existing eligible training partitions. Do not silently pool them across folds.
2. **Separate development from evaluation.** Official-definition-only rules and untouched public pretrained weights may be shared. Any report-derived vocabulary, prompt change or fitted threshold becomes fold-specific. Develop it only within the outer training side, using an inner split when reference labels inform selection; freeze before outer evaluation. Historical inspection of the same 58 studies means resulting OOF remains adaptive development evidence even when implementation is fold-clean.
3. **Measure reliability where reference labels exist.** For each target, report supervised call count, positive/negative count, confusion matrix, positive predictive value, negative predictive value, sensitivity/specificity where identifiable, and abstention/failure coverage. Separate metrics conditional on being supervised from all-reference-cohort coverage. Report denominator and interval for every rate; leave unsupported rates undefined. Report versus reference disagreement conflates extraction error with differences between report statements and image-derived assessment. Without a clinician, those causes cannot be resolved confidently.
4. **Evaluate new coverage directly.** Partition calls into agreement with deterministic extraction, disagreement, and new coverage; measure the latter separately. Agreement between two fallible labelers is not ground truth. A language model's verbal confidence is not calibrated correctness. Thresholds must be selected on training-side evidence; if positives/negatives are too sparse, leave the target unsupported rather than choose a persuasive global accuracy threshold.
5. **Audit multilingual behavior.** Determine language/mixed-language/unknown counts locally on eligible reports; report target coverage and reliability by language only where sample sizes permit. Do not assume the 58 references represent the languages of all 4,349 report-only studies. Direct multilingual extraction avoids a second translation stage; if translation is later tested, preserve original evidence spans and audit negation/severity separately. No translation vendor or hosted inference is needed for the proposed route.
6. **Preserve lineage and privacy.** Record model/tokenizer revision, quantization/runtime, prompt and output hashes, seeds, decoding settings, report digests, eligible/excluded cohort identities, schema failures, evidence locations and all adaptation sources. Keep source text and identifier-bearing evidence local; publish aggregates. Reject incomplete lineage and invalid schema before training.
7. **Test image benefit with a paired experiment.** Once a learnable image baseline exists, compare reference-only against one admitted report-derived route with matching initial weights, reference sequence, checkpoint policy and evaluation cohorts. Record both reference and weak-label exposures, time and supervised entries; do not conceal changed reference exposure in a fixed-total-batch mixture. Report paired OOF differences, per-target results and uncertainty, plus within-fold metrics if cross-fold score offsets persist. Higher extraction coverage is not the outcome metric for image inference.

## Decisions still needed

- Recover and freeze current official semantic definitions and confirm pretrained-model/derived-label eligibility; a public license alone does not answer competition rules.
- Choose between admitting an evaluated subset of frozen learned outputs and spending queue time on one local extractor. Both remain candidates, not jointly authorized experiments.
- Set a prospective target-level admission criterion, minimum support and weak-supervision exposure/weight budget without repeatedly tuning to all 58 references. With no additional clinician, unsupported targets may need to remain masked.
- Confirm language coverage, related-study grouping, local GPU memory/access and bounded extraction timing. None was measured by this research.
- Resolve image-learning failure before interpreting another small weak-supervision delta as decisive. Self-training from the current near-chance image model has no demonstrated trustworthy foundation.
